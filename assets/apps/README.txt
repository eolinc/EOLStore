Optional: real per-app art. Create a subfolder per app id, e.g.:

    assets/apps/nova-strike-vanguard/icon.png
    assets/apps/nova-strike-vanguard/hero.jpg
    assets/apps/nova-strike-vanguard/screenshots/1.jpg

Then point that app's "icon"/"hero"/"screenshots" fields in
data/catalog.json at these paths instead of the current procedurally
generated placeholder art.
