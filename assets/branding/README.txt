Drop the official EOLStore logo here as:

    eolstore-logo.png

Any image size or aspect ratio works - square, wide wordmark, tall mark,
small or large source file, it doesn't matter. The header box only fixes
the height (40px) so it fits neatly in the blue bar; the logo is scaled
down proportionally to fit (object-fit: contain), so it's never
stretched, squashed, or cropped, whatever resolution you upload.

Until this file exists, the header shows the text/monogram fallback
automatically (see index.html's onerror handler).
